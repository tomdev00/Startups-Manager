# Tomas Mendes - Internship 2024 

## Startup Project 
This initiative, undertaken during an internship at Albatroz Digital, is designed to delve into the realms of TypeScript, Fastify, React, and Ant Design (Antd) frameworks. The objective is to construct a RESTful API leveraging Fastify in TypeScript for backend functionalities, alongside developing a frontend interface utilizing React and incorporating Antd components.

## What I used!
For my project, I employed TypeScript and Fastify to build the backend, ensuring robust and efficient server-side operations. On the frontend, I utilized React alongside Ant Design (Antd) components to craft a user-friendly and visually appealing interface. This combination of technologies allowed me to develop a comprehensive application that balances functionality and aesthetics.

## What does the project include?
The project features a robust set of functionalities designed to enhance user engagement and administrative control. 
User Authentication ensures secure registration, login, and logout processes, safeguarding user data and privacy. 
Startup Listings offer a comprehensive view of available startups, facilitating easy discovery for users. 
The Favorite Startups feature allows users to personalize their experience by marking startups of interest, enhancing the relevance of the platform. 
Admin Utilities, on the other hand, empower administrators with the ability to manage startup listings through CRUD operations, ensuring the platform remains up-to-date and relevant. 
Together, these features contribute to a dynamic and user-centric platform, catering to both general users and administrators.
